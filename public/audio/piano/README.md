## Processing

30 notes (A, B, D#, F of each octave from A0, plus C8; 2–4 semitones apart). The source
file names are one octave low (`Player_vl2_rr1_A3.wav` is A4 = 440 Hz, per the folder's
`PitchValueConversionChart.txt`); files here use scientific pitch (`A4.m4a`, sharps as
`s`: `Ds4.m4a` = D#4). Each was summed to mono, trimmed to ~4 ms before the attack,
evened against its neighbours (±4 dB at most), normalised with one shared gain, cut at
-54 dB or 8 s with a 1 s fade, and encoded to AAC (.m4a, ~90 kbps mono).
