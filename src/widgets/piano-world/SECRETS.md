# 피아노 월드의 숨겨진 콘텐츠

플레이어에게는 일부러 알려주지 않는 것들의 목록이에요. **유지보수하는 사람만 보는 문서**라서 화면 문구에도, 옷장 힌트에도 이 내용은 나오지 않아요.

숫자는 코드의 상수를 옮겨 적은 거예요. 바꿀 땐 코드가 기준이고, 이 문서도 함께 고쳐주세요. 서버와 짝인 값은 `engine/course-contract.test.ts`, `engine/cave.test.ts`가 비교해요.

## 한눈에 보기

| 비밀 | 어디서 | 여는 조건 | 보상 | 엔진 | 화면 | 서버 |
|---|---|---|---|---|---|---|
| 폭포 뒤 동굴 → 구름 건반 | 섬 북서쪽 하프 폭포 뒤 | 폭포 뒤 동굴 안쪽의 작은 포탈로 걸어 들어가기 | 점프 코스 입장 | `island.ts` `CAVE_PORTAL` | `island/` | - |

## 1. 폭포 뒤 동굴 → 구름 건반

- 섬 북서쪽 하프 폭포(줄을 따라 걸으면 연주돼요) 뒤 절벽에 동굴 입구가 있어요(`CLIFF.caveX0`~`caveX1`).
- 동굴 안에는 밟으면 울리는 수정 세 개가 있고, 가장 안쪽에 작고 희미한 포탈(`hidden`)이 있어요. 이 포탈이 구름 건반 코스로 가요.

## 2. 점프 코스 3단계와 왕관

- 구름 건반 → 밤의 건반 → 폭풍의 신전 순서예요. 각 코스 꼭대기의 보물 뒤 포탈이 다음 코스로 이어지고, 신전 꼭대기는 홀로 돌아가요.
- 직접 링크(`?region=night` 등)는 앞 코스를 깬 뒤에만 열려요(`use-region-travel.ts`).
- 완주하면 왕관을 받아요.
  - 회원: 서버가 잰 기록이 있으면 열려요(`CharacterCatalog.REWARD_HATS`). 따로 저장하지 않아요.
  - 손님: 브라우저에 남은 최고 기록으로 열려요(`course-record.ts`).
  - 구름: 왕관 / 밤: **우주의 왕관**(`star-crown`) / 신전: 불꽃 왕관.
- 우주의 왕관은 5번 동굴의 열쇠이기도 해요.

## 3. 자정의 종 → 하늘섬

- 종탑(x 0, z -46, 지붕 높이 15.4) 계단을 올라 지붕 위 종에 다가가면(2칸 이내) 종이 울려요. 따로 누를 키는 없어요.
- 낮에는 한 번 울려요. **밤**(하늘 어둠 0.6 이상, 치는 사람의 현지 시각 기준)에는 열두 번 울리고, 별 계단이 하나씩 나타나요.
- 서버가 채널별로 10분(`SKY_OPEN_SECONDS`) 동안 열린 상태를 기억해요. 같은 채널 사람 모두에게 열리고, 나중에 들어온 사람에게도 남은 시간이 전달돼요.
- 별 계단은 종탑 둘레를 나선으로 돌아 종탑 북쪽 하늘섬(높이 약 27)으로 이어져요.
- 하늘섬의 별자리 발판을 I → IV → V7 순서로 밟으면 오러리(천체 모형)가 코드 진행을 연주하고, 섬 하늘에 별자리가 영구히 남아요(`world.sky-found`).
- 하늘섬에서 떨어지면 약 10초 동안 천천히 내려와요(`SKY_DRIFT`). 계단 사이 점프에서는 켜지지 않아요.

## 4. 고양이의 꿈 → 달고래의 바다

- 홀의 고양이를 **3번 쓰다듬으면**(`PETS_TO_FOLLOW`) "따라가 볼까요?" 문구와 함께 섬 남서쪽 풀밭(x -11, z 30)으로 걸어가요. 그 자리에 1분(`CAT_SIT_SECONDS`) 앉아 하늘을 보다가 돌아와요. 돌아온 뒤 다시 보려면 또 3번이에요.
- 산책은 **나에게만** 보여요. 고양이는 서버가 공유하지 않아서 같은 채널의 다른 사람에겐 건반 위에 그대로 있어요. 산책하는 동안 쓰다듬는 건 횟수에 들어가지 않아요.
- 고양이가 앉을 때 근처(22칸 이내)에 있으면 "냥" 두 음이 들려요.
- 그 자리(1.1칸 이내)에서 **앉기 감정 표현**을 2.5초 하면 달고래의 바다로 가요. 포탈은 보이지 않고 늘 그 자리에 있어서, 고양이 없이도 갈 수는 있어요. 다만 고양이 없이는 찾을 수가 없어요.
- 별의 바다 위 섬들(조개, 찻잔, 거꾸로 자란 나무, 달 등불)과 바다에 잃어버린 음 다섯 개가 숨어 있어요. 해파리 등불을 밟고 섬 사이를 건너요.
- 다섯 음을 모두 찾아 가장 높은 섬에 오르면 고래가 내려와 노래하고, 아기 달고래가 따라와요.
  - 회원: 바다에 60초 이상 있었고, 도착 지점에서 사람이 낼 수 있는 속도로 걸어와 꼭대기에 서 있어야 서버가 지급해요.
  - 손님: 브라우저에 저장돼요(`world.moon-whale`).
- 한 번 들어가면 직접 링크(`?region=whale`)가 열리고, 고양이 자리에 발자국이 보여요.

## 5. 환영 벽 → 별이 잠든 동굴

- 섬 북서쪽 하프 폭포 **서쪽 절벽**, x -75 지점이 환영 벽이에요(`ILLUSORY_WALL`). 바위에 몸을 붙이면 통과해요.
- 아무 표시가 없어요. **우주의 왕관을 쓰고 7칸 안으로 다가가면** 그 바위에만 별가루가 반짝여요.
  - 손님은 왕관을 고르지 않아서, 우주의 왕관을 **가지고만** 있으면 돼요. 동굴 안에서는 자동으로 써요.
- 동굴 안:
  - 왕관이 없으면 거의 아무것도 안 보여요.
  - 왕관이 있으면 빛이 차오르고, 벽의 별이 지나갈 때마다 깨어나요. 같은 채널에서 우주의 왕관을 쓴 회원의 빛도 동굴을 밝혀요.
  - 구성: 입구 → 별의 쉼터 1 → 기둥의 방 → 끊어진 다리(한 칸 점프) → 별의 쉼터 2 → 계단식 제단.
  - 낭떠러지에 떨어지면 마지막으로 켠 별의 쉼터에서 다시 시작해요.
- 제단 위 황금 목걸이는 왕관 빛 아래에서만 보이고 집을 수 있어요.
  - 동굴에 들어온 지 21.5초가 지나야 집혀요(서버가 20초 머문 뒤에만 믿어서).
  - 회원: 서버가 확인하고 지급해요. 확인하는 것: 제단 위 위치, 우주의 왕관 착용, 입구에서부터 사람이 낼 수 있는 속도로 왔는지(켠 쉼터로 되살아나는 건 괜찮아요), **다리 건너편 쉼터를 지났는지**. 서버는 이유와 함께 답해요(`CaveClaim`). "아직"(위치가 한 박자 늦음, 막 다시 연결함)이면 클라이언트가 곧 다시 묻고, "안 됨"(순간이동, 다리를 건너지 않음)이면 입구부터 다시 오라는 문구가 떠요. 승인된 뒤에야 획득 배너가 떠요.
  - 손님: 브라우저에 저장돼요(`world.necklace`).
- 한 번 들어가면 직접 링크(`?region=cave`)가 열려요.

## 옷장에서 숨기는 것

- 펫: 하나도 없으면 펫 칸 자체가 안 보여요.
- 황금 목걸이: 얻기 전엔 액세서리 목록에 없어요. 서버도 저장을 막아요(`CharacterService.validate`).
- 코스 왕관: 깨기 전엔 목록에 없어요.

## 손님 기록이 남는 곳

브라우저 `localStorage`의 `kordi:v1:` 아래예요(`shared/lib/storage.ts`).

| 키 | 내용 |
|---|---|
| `world.course-best.{clouds,night,ruins}` | 코스 최고 기록(ms). 있으면 그 코스 왕관을 가진 거예요 |
| `world.sky-found` | 하늘섬 별자리 완성 |
| `world.dream-found`, `world.moon-whale` | 꿈의 바다 발견, 달고래 |
| `world.cave-found`, `world.necklace` | 동굴 발견, 황금 목걸이 |
| `world.warp-stones` | 깨운 워프석 |
| `world.guest-name` | 손님 이름 |

## 테스트하며 둘러보기 (개발 서버에서만)

`window.__kordi`(`lib/debug-seam.ts`)로 위치를 옮기거나 밤으로 만들 수 있어요.

```js
__kordi.teleport = { x: -75, y: 0, z: -43 }; // 환영 벽 앞
__kordi.night = true;                         // 자정의 종이 밤으로 친다
localStorage.setItem("kordi:v1:world.course-best.night", "90000"); // 손님에게 우주의 왕관
```
